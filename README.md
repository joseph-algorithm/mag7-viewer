# MAG7 Interactive Return Viewer

Full-stack app visualizing daily returns for the MAG7 stocks (MSFT, AAPL, GOOGL,
AMZN, NVDA, META, TSLA).

- `backend/` — FastAPI + yfinance + pandas, `/returns?start=&end=` with in-memory caching
- `frontend/` — React 18 + TypeScript + Recharts, responsive per-ticker chart grid

Setup and run instructions to follow.
